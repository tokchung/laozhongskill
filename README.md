### 一、看见自己

#### 看见自己 · `laozhong-kanjian`

> 从"我就是这样"，走到"原来是这样——那我可以那样。"

**适合谁：**
- 总在关系、生活里反复栽在同一个地方，却说不清为什么；
- 被贴过标签——"你太敏感""你想太多""你太作"——听多了自己也信了；
- 分手、受挫后心里冒出一句："我到底是个什么样的人？"
- 想改变、想成长，但觉得"了解自己"这事太玄，不知道从哪下手。

**你能拿到什么：** 6 层自我了解框架 + 三重辨析 + 松绑四层 + 防卡壳机制 + 完整实操案例。

**触发方式：** `/看见自己` 或说"看见自己""我不了解自己""为什么我总在同一个地方栽跟头"。

#### 探索聊天室 · `laozhong-tansuo`

> 从"我被困住了"，走到"原来我还有这条路。"

三位心理学大师——弗洛伊德、阿德勒、荣格——以「创伤」「超越」「整合」的身份出场，按锁→推→拉递进结构，带你走一遍从看见到选择到整合的完整路径。全程不露名字，最后才揭晓。

**适合谁：**
- 心里堵着一件事，想找人聊聊，但不知道从哪说起；
- 试过"想开点""向前看""翻篇了"，但根本翻不过去；
- 在感情里反复遇到同一种人、在关系里反复掉进同一个模式；
- 不是来找标准答案的——是来找"我到底卡在哪一步"的；
- 对心理学好奇，但不想读教科书——想用对话的方式感受三种流派的碰撞。

**你能拿到什么：** 三人递进式深度对话 + 6 层追问 + 被耽误的事引导 + 一条从看见到行动的路径。

**触发方式：** `/探索聊天室` 或说"探索聊天室""我想聊聊我的困扰""我被困住了"。

### 二、内容创作

> 这一组自带老钟的口吻和风格基准。用在你自己账号上时，把「老钟味」换成你的口吻即可，框架和检查项可以直接用。

#### 脚本排版 · `laozhong-jiaobenpaiban`

把录音转写稿清理、排版、查措辞、查拗口、查前后矛盾，最后落盘验证。四道检查走完才出定稿。

**你能拿到什么：** 清理 → 措辞点选 → 拗口检查 → 矛盾核对 → 定稿 的完整流水线，以及一套可复用的改稿铁律。

**触发方式：** `/脚本排版`、"清理一下""排版"。

#### 结构重组 · `laozhong-jiegou`

不写新内容、不改句式、不改观点——只调整叙事顺序（正叙→倒叙、先反后正、时间线打散、五步结构），让旧脚本获得新生命。

**你能拿到什么：** 五种重组骨架 + 段级重排方法 + 改动标注规范。

**触发方式：** `/结构重组`、"帮我重组一下""换个结构""这个脚本结构太平了"。

#### 协作出稿 · `laozhong-xiezuochugao`

你自己脑子里有见解但组织不出来时用：先定方向、出结构表暴露缺口、用反问把料取出来、定稿时只核字数不改原文。

**你能拿到什么：** 一套"反问—收料—成稿"的协作流程，AI 不替你写，只帮你把已有的东西逼出来。

**触发方式：** `/协作出稿`、"这个脚本没写完""协助我把这个脚本完成""你反问我"。

#### 深度长文 · `laozhong-changwen`

把直播高价值段落、核心观点或一个选题，扩写成公众号定版长文（情感 / 亲密关系 / 原生家庭 / 自我成长）。

**你能拿到什么：** 场景开头 + 口播节奏 + 第二人称 + 先共情再带走 + 钉一个判断的长文写法。

**触发方式：** "写老钟的深度文章""把这个段落扩成定版长文""公众号长文"。

#### 朋友圈文案 · `laozhong-pengyouquan`

一次写一批能直接发的朋友圈：先读口吻说明书、样本优先，一批 N 条先分结构不一个腔调，人称不全是「你」，每条有具体画面，段尾不留句号。

**你能拿到什么：** 口吻样本 + 题材禁令 + 脱敏底线 + 交稿前逐句校对清单。

**触发方式：** `/朋友圈`、"写几条朋友圈""发圈""朋友圈文案"。

#### 七层提炼 · `laozhong-wenantiqu`

把视频文案 / 口播脚本提炼成七层结构：意识形态 / 核心观点 / 对事件的看法 / 金句 / 价值观 / 底层逻辑 / 可复用方法论。

**你能拿到什么：** 一套把成品稿拆回素材库的方法，后续写脚本查库即可。

**触发方式：** `/文案提炼`、"提炼文案""把脚本整理成素材"。

#### 维特根斯坦 · `laozhong-weitegensitan`

把维特根斯坦当创作伙伴而不是素材查询工具：概念、金句、口吻、咨询场景映射四个抽屉，在原文的自然接口处加深，化用不点名。

**你能拿到什么：** 概念辨析（语言游戏、意义即用法、家族相似等）+ 可化用的金句 + 咨询切入角度。

**触发方式：** `/维特根斯坦`、"帮我改这篇脚本/文案""这个脚本哪里能更深""帮我找句维特根斯坦金句"。

### 四、工具

#### 生图 · `laozhong-shengtu`

一句话出图，走豆包 Seedream / 火山方舟 Ark。管住模型选择、尺寸、水印、落盘命名和报错定位。

**前置条件：** 需要火山方舟的 `ARK_API_KEY`（`setx ARK_API_KEY "你的key"`，重开终端）。

**你能拿到什么：** 出图脚本 + 尺寸与模型选择规则 + 错误码对照表（429 是额度、404 多是模型没开通，别先怀疑 key）。

**触发方式：** "生图""出张图""画一张""生成图片""帮我做张图"。

#### 识图 · `laozhong-shitu`

直接用当前对话模型的原生多模态读图，识别本地图片或 URL 图片，输出文字描述或提取图中文字。

**前置条件：** 你的对话模型需要支持视觉输入。

**你能拿到什么：** 读图流程 + URL 图先下载再读的做法 + 落盘备用的写法。

**触发方式：** "识别图片""看看这张图""描述图片""帮我看看这个图""图片识别"。

## 两种使用方式

不管你会不会用 AI，都能用。

### 方式一：Skill 版（推荐，完整体验）★

安装后，AI 会化身对应 skill 的引导者，带着你一步一步走完全程。

```bash
npx skills add tokchung/laozhongskill
```

**前置条件：**
1. **Node.js** —— `npx` 命令来自它。没有的话去 [nodejs.org](https://nodejs.org) 下载安装（选 LTS 版）
2. **git** —— 工具靠它下载代码。没有的话去 [git-scm.com](https://git-scm.com) 安装
3. **至少一个受支持的 AI 工具** —— 支持 70+ 主流 AI 工具：Claude Code · Codex · Cursor · Windsurf · CodeBuddy · Zencoder · Qwen Code · Trae · Continue · Cline · Roo Code · Kilo Code · Goose · Droid · Junie · Lingma · iFlow CLI · Tabnine 等

**常见问题：**
- `npx: command not found` → 没装 Node.js，先装 Node.js
- `Cloning repository` 卡住 → 网络问题，确认能访问 github.com
- 装完在 AI 工具里没反应 → 重启一下 AI 工具，让它重新加载 skill

安装后在 AI 工具里输入对应触发词即可。

### 方式二：知识包（自己拿去用）

如果你不用上面那些 AI 工具，我们公开了完整的方法论文档。你可以：
- 当文档读，跟着走
- 贴到你自己的 AI 提示词里
- 拿去做 RAG、做自己的工具

所有文件在 `知识库/` 目录下，不依赖 skill 框架，独立可用。
